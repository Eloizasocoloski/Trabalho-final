🏴‍☠️ Caça ao Tesouro (Java)

Jogo em modo texto onde o jogador deve encontrar tesouros em um mapa 8x8 antes que as tentativas acabem.

🎮 Como jogar
Digite coordenadas (linha e coluna) para escavar
Objetivo: encontrar os 8 tesouros em até 25 tentativas

📊 Regras
Tesouro (T) → +10 pontos
Armadilha (A) → -5 pontos
Vazio → nada acontece

▶️ Execução
javac Trabalhofinal.java
java Trabalhofinal

🛠️ Tecnologias
Java
Scanner
Random
